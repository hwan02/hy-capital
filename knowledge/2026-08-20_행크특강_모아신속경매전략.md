# 모아·신속 구역 빌라 경매 → 매매 전략

> 출처: **[행크 무료특강] 2026 하반기, 한발 먼저 움직이는 서울 소액 투자 전략** (부자되는세상 / 행크에듀) · 캡처 2026-08-20
> 캡처를 그대로 옮기지 않고 **실행 전략으로 정리**한 문서입니다.

## 한 줄 방향 (확정)

**서울 모아타운·신속통합기획 선정지 안의 빌라(다세대)를, 경매로 시세보다 싸게 낙찰 → 전세로 투자금 회수(플피) → 조합설립·프리미엄 타고 매매(전매).**

찾는 물건 = `선정지` + `조합설립 임박` + `경매 저가` + `전세 ≥ 낙찰가` 네 개가 겹치는 곳.

---

## 1. 실전 사례 4건 — '실투자금 0원·플피' 패턴

| # | 지역 | 유형 | 포인트 |
|---|---|---|---|
| ① | 용산구 | 신속통합기획 | 조합설립 목전·속도 빠름 / **생애최초대출**로 실투자금 1억 대 상급지 진입 / 다물권자 물건 저가 매입 |
| ② | 중랑구 | 모아타운 | 허위 유치권 물건 빠른 협상 / 인테리어 빼고도 **1.5억+ 안전마진** / 조합설립 앞두고 거래 활발 |
| ③ | 양천구 | 모아타운 | 7~8월 조합설립 임박·실거래 활발 / 저가 안전마진 / **매매가보다 높은 전세**로 투자금 회수+α(플피) |
| ④ | 관악구 | 신속통합기획 | 속도·거래 활발 / **무더위+대출이슈로 입찰자 적어 최저가 낙찰** / 낙찰가<전세가 → 플피 |

**읽는 법**: ④처럼 남들이 안 들어올 때(비수기·대출막힘) 최저가로 잡고, ③처럼 전세를 낙찰가 위로 맞추면 실투자금이 0에 수렴.

## 2. 물건 고르는 기준 (입찰 전 6개 체크)

1. **선정지인가** — 모아타운 / 신속통합기획 '선정지' 안인가 (밖이면 전제 붕괴)
2. **속도** — 조합설립 임박, 동의율 거의 참, 거래·프리미엄 붙는 구간인가
3. **저가** — 낙찰가가 시세 대비 안전마진을 주는가
4. **플피** — 전세가 ≥ 낙찰가 인가 (투자금 회수 핵심, 낙찰 전 전세시세 확인)
5. **사업성** — 역 승강장 350m 이내 / 폭 20m 이상 간선도로변 50m 이내인가 (준주거 상향 대상 → 아래 5절)
6. **경쟁 낮은 타이밍** — 비수기·대출이슈로 입찰자 적은 때

⚠️ 권리분석: 유치권(허위 포함)·다물권자 물건 주의 → **경매 → 입찰 전 조사표**로 권리·명도부터 점검.

## 3. 지금이 타이밍인 이유 — 규제완화 3종

**① 조합설립 동의율 완화**
- 일반: 재건축 70%→70%, **재개발 75%→70%** (2027년 변경안)
- 모아타운(소규모주택정비법 §23, 2026.2.27~): 소규모 재건축 **75%→70%**, 소규모 재개발 **80%→75%**

**② 조합설립 기간 1년 → 4개월** (서울시 2026.8.19 보도자료, 8.18 시행)
- 구역지정 前 추진위 조기구성 + 75%↑ 동의 시 조합설립 병행 처리
- **365일 → 120일 (245일 단축)**, '31년 31만호 공급 가속화

**③ 모아주택 심의기준 손질** (서울시 2026.7.10 보도자료)
- 역세권·간선도로변 준주거 상향 → 일반분양 확대, **용적률 최대 500%**
- 제2종(7층 이하) '평균 13층' 기준 폐지 → **중·고층 아파트 가능**
- 주민공동시설 개방 의무 삭제 → 지상 설치 시 용적률 완화

> 한 줄: **더 쉽게(동의율) · 더 빠르게(기간) · 더 크게(용적률)** 지어지는 방향 → 선정지 초기 진입 기대값↑

## 4. 준주거 상향 '대상' 조건 (사업성 필터)

모아타운 내 **제3종일반주거지역** 중, 사업구역 면적의 **절반 이상**이
- 역 승강장 **350m 이내**, 또는
- 폭 **20m 이상 간선도로변 50m 이내**

용어: 역세권=승강장 중심 350m / 간선도로변=도로폭 20m↑ / 구역 둘레 1/8 이상 도로 접함 / 위원회 심의로 최종 결정.

→ 관심 구역이 '3종 + 역 350m / 간선 20m·50m'이면 용적률·층수 상방이 커 **프리미엄 상방↑**.

## 5. 내 상황 대입 (무주택 부부 · 현금 1,000만 · 생애최초)

- **자금**: 경락잔금대출 + 전세 회수로 실투자금을 낮추는 구조. 관건은 (a)경락잔금대출 한도·금리, (b)전세가 > 낙찰가. 현금 1,000만이면 보증금 기준 최저가 1억 내외부터 접근(총필요자금은 별도 계산).
- **생애최초 — 구분 필수**:
  - *생애최초 대출*(구입자금) = 사례 ①이 쓴 조달 수단.
  - *생애최초 특별공급*(청약) = 주택 취득 순간 소멸(소유 이력 자체가 결격일 수 있음).
  - **이 전략 선택 = 생애최초 특공 청약을 접는 것을 사실상 전제**. 방향을 정했으면 감수하는 비용.
  - 지킬 여지만 확인: ① 배우자 단독명의 시 나머지 한 사람 자격 잔존 여부, ② 주택 아닌 물건 우회 가능 여부.
- **에어비앤비 전입**: 낙찰·대출·1세대 판단(취득세 중과)에 영향 가능 → 낙찰 전 확인.

> ※ 세제·대출·청약 수치는 자주 바뀜. 위는 '확인 대상'이지 확정 사실 아님.

## 6. 도구 — 강사의 '임장 대시보드' (imjang-dashboard.vercel.app)

- 구역(자치구→구역)별 매물 관리. 매물 카드에 건물형태·전용·대지지분·방/화장실·매가·전세·공시가·**신청평형(추정)**·상태태그(사전조사/확정/관심/보류)·**분담금/수익 분석**.
- 네이버 매물 가져오기: **북마클릿('매물수집') → 네이버 부동산 지도 확대 → 버튼 → JSON 붙여넣기 → 분석**.
- 예시 매물: 마포구 망원동 459-7, 다세대, 전용 67.06㎡, 매가 9.0억, 방3, '모아타운구역내', 신청평형 44(추정).
- **HY CAPITAL 반영 검토**: 구역 단위 수집 + 네이버 임포트 흐름, 매물 카드에 신청평형·대지지분·분담금 필드 보강.
