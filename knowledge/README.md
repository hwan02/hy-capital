# 부동산 지식 자료실

강의 Q&A · 카페 칼럼 · 유튜브 요약 · 내 메모를 **한 곳에 모아 언제든 검색**한다.

## 어디서 보나

| 용도 | 위치 |
|---|---|
| **평소 찾아볼 때 (폰·PC)** | 앱 → **경매 → 자료실** 탭. 키워드 검색 + 태그 필터 + ⭐즐겨찾기 |
| 통째로 읽을 때 | 이 폴더의 `*.md` (GitHub에서 목차로 바로 이동) |
| 원본 데이터 | 이 폴더의 `*.json` (앱에 넣는 소스) |

## 새 자료 추가하는 법

1. **자료를 준다** — 카톡 CSV / PDF / 캡처 / 링크 아무거나. Claude가 파싱해서
   `knowledge/YYYY-MM-DD_주제.json` + `.md` 로 만든다.
2. **앱에 넣는다**
   ```bash
   HY_PASSWORD='앱_비밀번호' python3 knowledge/import.py
   ```
   같은 (출처, 제목)은 자동으로 건너뛰므로 여러 번 돌려도 안전하다.
3. 앱 **자료실**에서 바로 검색된다.

> 짧은 메모는 파일 만들 필요 없이 앱 자료실 탭에서 **＋메모** 로 바로 추가.
> 스크린샷 PDF(카페 글 캡처 등)도 그대로 주면 파싱해서 넣는다.

## 암호 걸린 PDF

강의 자료 PDF에 암호가 걸려 있으면 내용을 읽을 수 없다. 암호를 **키체인에 한 번만** 넣어두면
그 뒤로는 자동으로 열린다. 암호는 이 저장소에도, 대화에도 남지 않는다.

```bash
# 1) 한 번만 — 입력한 글자는 화면에 보이지 않는다
security add-generic-password -a "$USER" -s hy-pdf-lecture -w

# 2) 그 다음부터는 이것만
python3 knowledge/unlock_pdf.py '~/Downloads/강의자료.protected.pdf'
```

`.unlocked.pdf` 가 원본 옆에 생긴다. 그 뒤 `/hy-knowledge` 로 자료실에 넣는다.
자료마다 암호가 다르면 `--service hy-pdf-다른이름` 으로 항목을 나눈다.

> **복호화된 사본은 커밋하지 않는다.** 이 저장소는 공개이고, 유료 강의 자료다.
> `*.unlocked.pdf` 와 `*.pdf` 는 `.gitignore` 에 있다.

## JSON 포맷

**Q&A형** (강의 질의응답)
```json
{
  "meta": { "source": "출처", "lecture": "강의명", "expert": "답변자", "qa_date": "2026-08-19" },
  "items": [
    { "question": "...", "answer": "...", "asker": "질문자", "tags": ["세금","재개발"] }
  ]
}
```

**글/칼럼형**
```json
{
  "meta": { "source": "네이버카페 행크에듀", "author": "부자되는세상", "date": "2026-08-18" },
  "items": [
    { "title": "제목", "body": "본문", "tags": ["재개발"], "kind": "article" }
  ]
}
```

## 태그 체계

`세금` `대출` `재개발` `경매` `단기임대` `명의전략` `갈아타기` `현금흐름` `지역` `초보전략` `강의안내` `정책` `에어비앤비`

한 항목에 여러 태그가 붙는다(예: 재개발 빌라 취득세 질문 → `세금`+`재개발`).

> **`에어비앤비` 태그는 화면을 가른다.** 이 태그가 붙은 항목만 앱 **Airbnb → 자료실** 탭에
> 보인다(`KnowledgeView(onlyTag: '에어비앤비')`). 숙박업 관련 자료에는 반드시 붙인다.
